## How to open the labs
1. Install Cisco Packet Tracer (free through Cisco Networking Academy).
2. Download a `.pkt` file from a lab folder.
3. Open it in Packet Tracer (same version or newer).

## What's in each lab folder
- `README.md`: goal, topology, addressing, and notes
- `*.pkt`: Packet Tracer file
- `topology.png`: screenshot of the network
- `configs/`: saved device configs
